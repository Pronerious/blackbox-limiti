# Limiti di temperatura per BlackBox

Questo repository contiene **solo un file di dati**: [`limiti.json`](limiti.json), la tabella dei
limiti di temperatura ufficiali di processori e schede video (AMD, Intel, NVIDIA), con la fonte
ufficiale per ogni riga.

Lo scarica il pulsante **Aggiorna i limiti** di BlackBox, solo quando viene premuto. Non
contiene programmi né codice.
